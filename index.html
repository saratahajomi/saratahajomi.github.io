Selected work

Research

01

Automated Ground-Motion Classification

Machine-learning framework for automated usability classification of earthquake ground-motion recordings, combining signal-processing and pattern-recognition features with scalable Python workflows.

Machine LearningGround MotionPython
02

Rainfall-Triggered Landslide Hazard

Probabilistic hazard assessment combining landslide susceptibility with rainfall-threshold analysis and statewide geospatial datasets to support risk-informed infrastructure planning in Virginia.

Probabilistic ModelingGISLandslides
03

HVSR Site Characterization

Field and analytical investigations using ambient-vibration HVSR measurements and co-located CPT data to examine site frequency, subsurface conditions, and coastal site response.

HVSRSite ResponseCPT
