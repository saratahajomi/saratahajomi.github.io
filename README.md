# Sara Tahajomi Banafshehvaragh — Academic Portfolio

A static academic portfolio designed for GitHub Pages.

## Publish on GitHub Pages
1. Create a public repository named `YOUR-USERNAME.github.io`.
2. Upload everything in this folder to the repository root.
3. In GitHub, open **Settings → Pages** and choose **Deploy from a branch**, `main`, `/ (root)` if Pages is not already enabled.
4. Your site will appear at `https://YOUR-USERNAME.github.io/`.

## Customize
- Replace the `ST` monogram with a headshot later if desired.
- Update `assets/Sara_Tahajomi_CV.pdf` whenever your CV changes.
- Publication links are in `index.html`.

The public page intentionally omits the street address, phone number, and reference contact information from the CV.
